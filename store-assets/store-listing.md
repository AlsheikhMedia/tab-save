# Store Listing Copy

## Short Description (132 chars max)
Save all open tab titles and URLs to a text file with one click. No data collection, no accounts, fully offline.

## Detailed Description (Chrome Web Store & AMO)

Tab Saver exports all your open browser tabs — titles and URLs — into a clean, plain text file with a single click.

**How it works:**
• Click the Tab Saver icon in your toolbar
• Every open tab across all windows is captured
• A text file downloads instantly with each tab's title and URL

**Why Tab Saver:**
• One click — no popups, no configuration, no sign-up
• Fully offline — zero network requests, zero data collection
• Lightweight — under 5KB, no background processes
• Open source — MIT licensed, code on GitHub

**Use cases:**
• Save your research session before closing tabs
• Share a set of links with a colleague
• Bookmark dozens of tabs at once as a backup
• Archive your reading list or work context

**Privacy:**
Tab Saver requests only the "tabs" permission to read tab titles and URLs. It makes no network requests, stores no data, and has no analytics. Your tabs stay on your device.
